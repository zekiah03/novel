## ■ 矛盾リスト

### 矛盾① ★最大 ─ 勇者3人組 vs 邪神 vs エルフ

| 事実 | 出典 |
|------|------|
| 邪神は**腕の一振りで男性エルフ全員(世界最強種)を全滅**させた | 原文02 |
| 人類は**1000年間負け続けた** | 原文10 |
| **高校生3人が討伐した** | 原文10 |

→ **世界最強種の男性全員が一撃で消える相手を、高校生3人が倒した**ことになる。
→ 素直に読むと「勇者3人 > エルフ全員」だが、フェフェルは「武力で敗北した経験がほぼない」【原06】。

**解決案**:
- (a) 邪神には**正面戦闘以外の倒し方**があった(封印の解除条件、核の破壊、条件付き無敵の看破など)。エルフは正面から殴りに行ったから死んだ
- (b) 1000年で人類側の**技術・魔法体系が進歩**した(統一王の言語統一、記録者の記録技術の蓄積)
- (c) 勇者は**特別な系譜**(完全理解者に近い、あるいは邪神を倒すためだけに存在する枠組み)
- (d) 邪神は1000年かけて**弱っていた**(消耗説)

→ **(a)+(b)の組み合わせが自然**【推】

### 矛盾② ─ 誰がフェフェルを封印できたのか

| 事実 | 出典 |
|------|------|
| フェフェルは兵十二人に囲まれても無傷で離脱する | 原文02 |
| **別世代の勇者が毒ダンジョンに封印した** | 著者確定A9 |

→ 倒せないものをどうやって閉じ込めたのか。
→ 同じ問題が**封印エルフたち**にもある(人間が「殺せなかったので封印した」)。

**解決案**: この世界には**「封印」という確立された技術体系**があり、殺害より封印のほうが現実的な対処法になっている【推】。
実際、防音結界・時間結界・惑星規模結界と**結界技術が異様に発達している世界**なので、結界=封印の系統技術と整理すると一貫する。

### 矛盾③ ─ フェフェルと恭子とチャイの上下

三者とも「単独で災害級」だが、**直接比較できる記述が一つもない**。

- フェフェル: 腕一振りで集団消滅。エルフの素の性能
- 恭子: 最上位魔法(戦略兵器級)の無制限連射。気の循環効率が異常
- チャイ: 歴代最強。ただし**無意識の防衛反応**であって制御していない

→ 最終決戦で共闘/対決する可能性があるので、**序列を決めておかないと後で困る**。

### 矛盾④ ─ 魔法体系が話ごとに違う

| 話 | 体系 |
|----|------|
| 恭子編【原12】 | 武道→気力→放出→制御→現象化(魔法)。**感情・精神圧力が燃料** |
| エルフ編【原01】 | 魔法に愛された種族。森の制御。詳細不明 |
| 結界系【原04・07・09】 | 防音結界・時間結界・惑星結界。燃費と規模の概念 |
| フェフェル | 金属生成・鎖生成・超高速移動 |

→ **同一の体系なのか、別系統が併存しているのか未確定。**
→ 恭子の「気」体系でフェフェルの鎖を説明できるか?

### 矛盾⑤ ─ 「事故で死ぬ」ルールの適用範囲

瞑迷は**加熱不足のポップコーン一粒で頭部が崩壊して死亡**した【原18】。
物理法則が過剰な世界なので、条件が揃えば強者でも死ぬということになる。

→ ではフェフェルやチャイも、同じ理屈で事故死しうるのか?
→ **「強さ」と「死ににくさ」が別物**という整理なら成立するが、明示が必要。
