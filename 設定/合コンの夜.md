**著者確定**: 合コンの場そのものが、フェフェルに巻き込まれる。あの夜、実際にハニー選別が起きる。

## 構造の照応 ★この繋がりの核心

**合コンとハニー選別は、同じ構造をしている。**

| ハニー選別 | 港区合コン |
|-----------|----------|
| 複数の女が一人の男に「本物」と認定されるために争う | 複数の女が一人の男に選ばれるために争う |
| 「ハニー選別ルール整理」という文書がある | **「少女漫画学」**という学問が同じことを理論化している |
| 主人公属性・当て馬・王子 という役割分担 | 同上(少女漫画学の用語そのもの) |
| 負けた側は死ぬ | 負けた側は「一番心が疲れていた人物」になる |
| フェフェルは選ばせるだけで自分では決めない | **無能王子も自分からイベントを作らない。女同士が勝手に争う** |

→ **無能王子はフェフェルの無害版**。どちらも「何もしないのに女が争う男」。
→ 少女漫画学は、**ハニー選別のルール整理と同じもの**を、血を流さない場で書いている。

**その夜、比喩が現実になる。**

### 年齢の食い違いの処理【Claude判断・差し替え可】

原文19は「三人とも30歳前後」と書いているが、原文05の**麗華30・真凛25・心菜20**を採った。

理由は、年齢がそれぞれの人物の芯だから。
心菜20=看護学生の若さ、真凛25=港区の全盛期、麗華30=「強い女」に疲れている年齢。
どれも動かすと人物が壊れる。

**フェフェルは目が悪いので、年齢差は見えていない。**
彼が見ているのは「濃いメイク・ショートヘア・体つき」だけ。
むしろ**十歳ずつ離れた三人を同じ顔だと思う**ほうが、誤認の異常さが出る。

→ 本文023で、三人がホテルで**同じメイクをして「おそろい」になる**場面を作った。
　真凛が心菜に謝る代わりにメイクをしてやり、麗華も巻き込まれる。
　**この夜いちばん優しい場面が、翌朝の全滅の条件になる。**

## 各人物がこの構造でどう動くか【推・要検討】

- **麗華**: 唯一の戦闘者。だが彼女の役回りは「守る側・締める側」。**守ろうとして負ける**形が一番この人らしい
- **真凛**: 「選ばれる」より「負けない」。**選別で最も生き残る資質を持っている**。しかも本人に悪意の自覚がない
- **心菜**: 根が善人で計算しない。**選別に最も向いていない**
- **千尋**: 観察者。何が起きているか最初に理解する可能性が高い
- **圭介**: 中身のない喋りが、極限で何になるか
- **悠真**: 「これ変じゃないかな」と考え続ける男が、明らかに異常な事態を前にどうするか

## ★N3(時代の位置)について【要著者確認】

N2が確定した結果、**赤の一生(10〜80歳)は王都の時間結界の内側の時代**に置かれることになった。

- 合コン編は原文05の時点で **LINE・終電・コンビニ夜勤・IT企業・港区・少女漫画学** がある
- その三人が30歳の赤と同じ日に選別される
- → 赤の一生は**発展期以降**、しかも**王都の時間結界が張られたあと**

**つまりフェフェルの封印は、赤が死んだあと(城の投票編のあと)ということになる。**
`設定/時系列.md` の「封印 → 解放 → 集結編」の順は保たれるが、
**赤の物語まるごとが「解放後」に入る。**

これでよいか、著者確認をお願いします。
問題があるとすれば、014「明日にする」で
「町が大きくなって道に石が敷かれ、字を書くようになった」と書いた程度の発展度と、
合コン編の現代社会に開きがあること。

**吸収案**: フェフェルの家は**王都の外**(018で「東の街道沿い」と書いた)。
王都の内側だけが数百年先を行っているので、
**フェフェルは買い物のたびに王都へ入り、そこで「ハニー」を拾ってくる。**
外の田舎家と、内側の現代都市が、彼の徒歩圏で地続きになる。
→ この読みなら矛盾しない。014の町は王都の外の町でよい。
