### ★10歳で彼女が学んだこと(原文19からの差し替え)

原文19は「次は自分で最後までやらなければならない」と書いているが、
016では**すでに自分で最後までやっている**。したがって、彼女が持ち帰るのは別のものになる。

- **フェフェルは確かめない。**部屋に入ってきて、目を細めて、それで終わりだった
- **本物が死んでも、この人は気づかない。**「また一人に戻ってる?」と言って安心した
- **黙っていれば、自分が本物になる**
- そして――**言わなかった。**言えば一言で済んだのに、言わなかった

→ この一夜が、20歳の「最初から殺す気だった」と、
　30歳の「白を守り、青を守り、休憩を提案して裏切る」冷徹さに、まっすぐ繋がる。
→ **彼女は10歳の時点でもう、優しさの側にいない。**

### ★この決定が確定させたこと

**本物のシエラの転生体は、10歳のあの夜に死んだ。**

以後の20歳・30歳・城の投票編に出てくる「ハニー」は、
**一人残らず、本物とは無関係の他人**ということになる。

## 鎖と選別魔術【新設定・重要】

- 鎖は**極めて頑丈で基本的に解除不能**。長さは約一メートル
- 拘束された者同士は遠くへ離れられず、**立ち上がることすら難しい**
- **後年、鎖に「一定時間後に一人へ戻す」選別魔術が組み込まれた**
  - 規定時間までに一人にならなければ、**鎖側がランダムに生存者を決定する**
  - 4人選別では規定時間 = 二十四時間
- → **本文014「明日にする」の時点ではまだ選別魔術は無い。**
  最初の選別(10歳)は「フェフェルが朝に判断する」だけが期限だった

### フェフェル本人の認識

目も耳も悪いため、彼の理解は次の程度しかない。

- 「なんか異音がする」
- 「ハニーが何人かぐちゃぐちゃになってる」
- 「しばらくすると一人に戻る」

だから怒らない。憎まない。**一人に戻ったのを見て安心する。**

> 「また一人に戻ってる?」

そして生き残ったハニーを抱きしめる。

## ドレインの本来の用途【新設定・重要】

**ドレインは本来、戦闘用の魔術ではない。**

- 口づけによって生命力を少し分けたり、受け取ったりする魔術
- **挨拶や祝福に近い文化的な用途**のもの
- 極限状態でのみ、生命力の奪い合いに転用できる
- 即効性は低い。長時間、密着し続けなければならない

→ **祝福の儀式が、殺害手段として使われる。**
これも「優しさ由来の地獄」の一形態として機能する。

※`設定/世界観.md` の「ドレイン: 接触型生命力吸収」の記述はこれに更新済み

## 幽霊・魂・来世【新設定・重要】

**この世界では、幽霊も魂も来世も完全に存在する。**
みんなそれを信じているというより、**事実として知っている。**

→ だから赤は、死んだ青へ普通に話しかける。返事がなくても聞いていると確信している。

> 「ねぇ青」「あとちょっとだったのにね」「もう少し私を仕留めるの早かったら、生き残ってたのに」
> 「青って計算速いタイプだったよね?」「なのにそこ計算できなかったの?」「もしかして頭悪い?」
> 「さっきまで勝ち誇ってたくせに」「そんなことになっちゃって」「ダッサぁ……」
> 「ということで」「バイバイ」「またね」

**来世でまた会うと確信して別れる。**

→ この設定は**シエラの「また来世でねっ」(本文011)と直結する。**
　来世が事実として存在する世界だから、シエラの嘘は「嘘」として成立しにくい。

## 緑・青・白(30歳の選別)

| 色 | 性格 | 最期 |
|----|------|------|
| **赤(主人公)** | ルールを唯一知っている。戦術家 | 生き残る |
| **緑** | 明らかに強い。理解が早い。ただし**勧誘が下手**(血だらけの顔で「こっち来て」) | 3人がかりのドレイン+殴打で二日かけて死ぬ |
| **青** | 「有利な側につく」性格。計算が速い。最後に勝ちを確信する | **時間切れのランダム選別で消える** |
| **白** | 弱い。泣き虫。怖がる。**それでも助けに戻ってくる** | 追い詰められ、**自分の意思で降りる**。赤に寄りかかって静かになる |

三人は**前日に酒場の合コンで出会った仲**。全員30歳前後の美人、全員ショートヘア、
全員胸が大きい。そして偶然、**三人とも赤に似た濃いメイクをしていた。**

→ フェフェルは赤を探して宿へ行き、同じメイクの女が三人いたので全員連れて帰った。

### 赤の戦術(30歳選別)

1. 最悪シナリオ = 白が先に死ぬ → 青が「緑が勝つ」と判断 → 青が緑につく → 2対1で潰される
2. だから **白を守る**。そして青が起きた時に**「赤が勝っている」ように見せる**
3. 緑を倒すより先に**緑を血だらけ・傷だらけにして見た目を酷くする**
4. 青が目覚めた瞬間だけ、余裕の表情を作る
5. 緑は焦って本気を出す → 青は逆に緑を怖がる → 青が赤側につく
6. 3対1。白と青が緑にしがみついてドレイン、赤が正面から止める
7. 緑が死んだ後、白と青は**赤を怖がる**(最後まで仕留めた人間だから)
8. 赤は「休も」と言って休憩し、**警戒が緩んだ瞬間に襲う**(白狙い)→ 青が助けて2対1
9. 白が自死を選ぶ。赤と青が言葉だけで白を引っ張り合う。白は赤側で降りる
10. 1対1。だが赤は限界。青が勝ちを確信 → **その瞬間フェフェル帰宅 → 時間切れ → 青がランダムで消える**

## 城の投票編(80歳〜)

### おばあちゃん=ハニーになった経緯

赤がたまたま**すっぴんで外出**した日、フェフェルは彼女を見失う。
そして通りかかったおばあちゃんを見て「ハニー?」。次のおばあちゃんも「ハニー?」。また次も「ハニー?」。
→ フェフェルの中で **「おばあちゃん=ハニー」** という認識が生まれる。

→ **化粧が「赤」の識別子だった。**シエラが教えた「顔なんて入れ物でしょ」の最終形。

### 収集

市場・病院・教会・畑・家。「ハニー迷子になるからぁ」という善意で、何百人以上を大きな施設へ。
全員に透明な鎖。「いっぱいハニーいて安心だぁ」。本人にもどれが本物か分からない。

### 城

> 「こんなにいっぱいハニーいるならぁ」「もっと広いおうち必要だねぇ」
> 「すっごい立派なの建ててくるねぇ」「みんなでお引越ししよぉ」
> 「庭も作るからねぇ」「お花いっぱい植えよぉ」

豪華な城。庭・花・噴水・食事・風呂・衣服。**老人達には快適すぎて、最初は誰も危機感を持たない。**

### 投票ルール【確定】

- **票が多い者ほど生き残る確率が高い**
- **投票しなかった場合、投票確定の瞬間に最も近くにいる相手へ自動的に一票入る**
- **確定タイミングは誰にも分からない**

→ 近づきすぎると自動票が相手へ流れる。孤立すれば手動票がもらえない。
→ **近づきすぎても危険、離れすぎても危険。**

### なぜ伝達に一年かかるか

おばあちゃん達は目が悪い・耳が悪い・記憶が曖昧・会話が遅い・保守的で新概念を信用しない。
スピーカーのような道具もない。主人公自身も声が大きくない。**伝言ゲームしかない。**

主人公も説明の途中で自分で忘れる。

> 「えっとねぇ……」「この投票ぉ……」「え?」「だからぁ……」「なんだっけぇ……」
> 「あ、そうそう」「票入れないとぉ……」「近くの人に入っちゃうのぉ」

伝言されるたびに変質する:

```
「近くの人が危ないらしい」→「近くにいると危ない」→「離れた方が票もらえるらしい」
「仲良い人と近づくと票が入る」→「仲良くした方がいい」→「人気者の近くにいれば安全」
```

一日かけて説明しても、理解できたのは**一割程度**。

### 鎖の変化(危機感が生まれるまで)

赤に近づくと鎖が少し熱くなる。「熱っ」。そして小さな音。

```
「ピ……」→「ピ……ピ……」→「ピピ……」→「ピピピピ……」
```

透明だった鎖の一部が、細く、鋭く、高熱を帯び、**首周りへ食い込むような形へ変わり始める。
まるでレーザーカッター。**

一ヶ月→二ヶ月→半年。ここでようやく「主人公が言っていることは本当かもしれない」。
**一年後**、大枠が城全体へ普及する。

### 一番生きたがるおばあちゃん

威張る。声が大きい。自信満々。「あたしは絶対生き残る!」「運も実力なのよぉ!」「最後は気合いよぉ!」

周囲には「もう十分生きたしねぇ」「こんな終わり方でもいいかもねぇ」と考える人もいる。
だが彼女だけは違う。**絶対に生きたい。**

その執着・声の大きさ・存在感、さらに**耳の悪い人にも声が届く**。
その結果、皮肉なことに**どんどん票を集める。**最初は嫌われていたのに、
やがて「この人についてた方が安心かも」という空気が生まれる。

### フェフェル、宇宙へ

> 「最後のお星さまとってくるねぇ」
> 「ちょっと宇宙行ってくるぅ」(近所へ買い物へ行くような調子)
> 「たぶん一ヶ月くらいかなぁ」

→ この「一ヶ月」が、彼女達にとっての目安になる。**その一ヶ月が本当の選挙期間。**

### 投票社会

席順が政治になる。隣に誰がいるか。廊下で誰と歩くか。庭で誰の横へ座るか。
誰がお茶を運ぶか。誰を手伝うか。全部が票に繋がる可能性がある。

**ものすごく遅い速度で、選挙だけが進んでいく。**

### 会話が成立しない選挙

> 「あなた誰に入れるの?」「え?」「投票」「**豆乳?**」「違うぅ……」

数十分かかる。途中で「今日魚だった?」「昨日じゃない?」へ逸れる。元へ戻れない。
誰かが寝る。誰かが忘れる。誰かが聞き間違える。誰かが勝手に意味を補完する。

→ **一つの政策が城の反対側へ届く頃には、全く違う意味になっている。**
