# 時系列(作中年表)

## ★世界は「フェフェルの封印」を境に二つの時代に分かれる【著者確定】

| | **封印前** | **封印後(解放時)** |
|---|---|---|
| 文明 | **狩猟時代的** | **標準的な異世界ファンタジー** |
| 該当する話 | エルフ編・フェフェルの放浪・シエラとの出会い・ハニー選別・城の投票編 | 集結編・勇者編2〜3章・パン屋編・猫の国・悪役令嬢編ほか |
| フェフェルの立ち位置 | その時代を生きる異物 | **前時代の生き残り。時代錯誤の存在** |

→ フェフェルは**封印されている間に、世界が丸ごと作り変わった**。
→ 解放されたとき、彼が知っている世界はもうどこにもない。
→ 「生きているうちに神話になった」のではなく、**神話になってから起こされた**。

### なぜ時代が変わったのか(因果)【推・要確認】

**邪神が討伐されたから**、と読むと綺麗に繋がる。

- 邪神は千年にわたり国を滅ぼし、都市を消し、魔物を暴走させ続けていた
- **そんな環境では文明が積み上がらない**。だから狩猟時代的なまま停滞していた
- 勇者3人が邪神を討伐 → **初めて世界が安定した**
- そこから文明が一気に立ち上がり、標準的な異世界の姿になった
- さらに後年、ハンの時間結界で王都だけが突出する

→ つまり時代区分はこうなる:

```
【停滞期】邪神の千年災害 … エルフ滅亡・フェフェル誕生・シエラ・封印
        ↓ 邪神討伐(勇者3人組)
【発展期】標準的な異世界 … 国家・ギルド・貨幣経済が成立
        ↓ ハンの時間結界
【王都のみ超発展】現代的社会 … コンビニ・SNS・地下アイドル
```

**フェフェルは停滞期に封印され、発展期に解放された。**

### ⚠ 未解決の矛盾 ─ 原文01の文明レベル

**原文01(エルフ編と同時代)には、狩猟時代と両立しない描写がある。**

> 世界中の**人工衛星**。各国軍。企業。宗教。**投資市場**。
> 人工栄養剤。合成タンパク。培養脂質。無機ビタミン。
> **学校給食も、軍用食も、高級レストランも。全部、化学物質。**

これは現代を超えた化学文明であり、「封印前=狩猟時代的」と正面から食い違う。

**著者確認待ちの三案**:

| 案 | 内容 | 影響 |
|----|------|------|
| A | 原文01が正(封印前も高度文明) | 「狩猟時代的」を撤回。封印後のほうが文明が退化していることになる |
| B | 「狩猟時代的」が正 | 原文01の高度文明描写を削る。**人類の化学物質依存という設定も消える** |
| **C(推奨)** | **両方生かす** | かつて高度文明があったが**邪神の千年災害で崩壊し狩猟時代まで退行**。衛星や投資市場はさらに前の時代の遺物。封印後はゼロから積み直した文明 |

**C案を推す理由**:
1. 原文01の描写を捨てずに済む(化学物質社会も資源独占の重みも残る)
2. 完全理解者の系譜と噛み合う。**直立革命家**(二足歩行を広めた)や**記録者**(記録を発明した)は明らかに文明最初期の存在。文明が一度リセットされて積み直したと考えれば位置づけが自然になる
3. フェフェルの立ち位置が最も切なくなる。**崩壊しきった世界で生まれ、封印され、積み直された世界で目覚める。同じ場所なのに、二度とも自分の居場所ではない**
