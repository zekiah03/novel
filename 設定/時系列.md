# 時系列(作中年表)

## ★世界は「フェフェルの封印」を境に二つの時代に分かれる【著者確定】

| | **封印前** | **封印後(解放時)** |
|---|---|---|
| 文明 | **狩猟時代的** | **標準的な異世界ファンタジー** |
| 該当する話 | エルフ編・フェフェルの放浪・シエラとの出会い・ハニー選別・城の投票編 | 集結編・勇者編2〜3章・パン屋編・猫の国・悪役令嬢編ほか |
| フェフェルの立ち位置 | その時代を生きる異物 | **前時代の生き残り。時代錯誤の存在** |

→ フェフェルは**封印されている間に、世界が丸ごと作り変わった**。
→ 解放されたとき、彼が知っている世界はもうどこにもない。
→ 「生きているうちに神話になった」のではなく、**神話になってから起こされた**。

### なぜ時代が変わったのか(因果)【推・要確認】

**邪神が討伐されたから**、と読むと綺麗に繋がる。

- 邪神は千年にわたり国を滅ぼし、都市を消し、魔物を暴走させ続けていた
- **そんな環境では文明が積み上がらない**。だから狩猟時代的なまま停滞していた
- 勇者3人が邪神を討伐 → **初めて世界が安定した**
- そこから文明が一気に立ち上がり、標準的な異世界の姿になった
- さらに後年、ハンの時間結界で王都だけが突出する

→ つまり時代区分はこうなる:

```
【停滞期】邪神の千年災害 … エルフ滅亡・フェフェル誕生・シエラ・封印
        ↓ 邪神討伐(勇者3人組)
【発展期】標準的な異世界 … 国家・ギルド・貨幣経済が成立
        ↓ ハンの時間結界
【王都のみ超発展】現代的社会 … コンビニ・SNS・地下アイドル
```

**フェフェルは停滞期に封印され、発展期に解放された。**

### ★世界は三度、姿を変える【C案・著者確定】

原文01の高度文明描写(人工衛星・投資市場・化学物質社会)は**失われた前文明のもの**。

```
【第一文明期】高度化学文明
　　エルフが生命資源99.9%を独占 → 人類は化学合成へ振り切る
　　人工栄養剤・合成タンパク・人工衛星・投資市場
　　「天然水は宝石並みの価格」「本物の土を知らない」
　　　↓
　　【邪神の出現】千年災害。国が滅び、都市が消え、魔物が暴走
　　　↓ 文明崩壊
【停滞期】狩猟時代 ← ★エルフ編はここ
　　化学の生産基盤が失われ、人類は狩猟採集へ退行
　　前文明の遺物と遺跡だけが各地に残る
　　自然に頼るしかないのに、その自然はエルフと森が拒む
　　　↓
　　【邪神討伐】勇者3人組。千年ぶりに世界が安定する
　　　↓ ゼロから積み直し
【発展期】標準的な異世界 ← ★封印後のフェフェルはここへ解放される
　　国家・ギルド・貨幣経済が成立
　　　↓
　　【ハンの時間結界】
【王都のみ超発展】現代的社会。コンビニ・SNS・地下アイドル
```

**この構造が生むもの**:

1. **原文01の設定が全部生きる。** 化学物質しか食べない社会も、エルフの資源独占の重みも、失われた過去として保持される
2. **完全理解者の系譜と噛み合う。** 直立革命家(二足歩行)や記録者(記録の発明)が文明最初期の存在であることが自然になる
3. **フェフェルの立ち位置が最も切ない。** 崩壊しきった世界で生まれ、封印され、積み直された世界で目覚める。**同じ場所なのに、二度とも自分の居場所ではない**
4. **ノラが森の奥へ入った理由が強くなる。** 化学の生産基盤が失われた世界では、薬も食料も自然から採るしかない。だが自然はエルフのものだった
