# フェフェルに関わる女性(整理)

フェフェルの人生を貫く「喪失と探索」の相手たち。本作の背骨。
※正史の順序は フェフェル.md の「正史シーケンス」と一致させること。

## 2. 幼少期の人間女性(最初の一目惚れ・名前未設定)

- 幼少期、村へ侵入してきた人間女性。フェフェルが**人生で最初に一目惚れした相手**(原文02・著者回答「残す」)
- その女性は戦闘で死亡 → フェフェルは「人間」に強い興味を持つ
- **意味**: シエラ(初代ハニー)より前に、既に一度「好きになった相手を失う」体験をしている。「探す愛」「喪失耐性」の最初の種

## 3. シエラ(=初代ハニー) ★最重要

- スラム街の双剣士。フェフェルが人間世界で出会い、興味を持った相手
- **シエラ=初代ハニー**(著者回答で確定)。フェフェルにとって「ハニー」の原点
- シエラがフェフェルに**名前を付けた**(「フェフェル」を名乗る起点・B7)。「メガネがない方が似合う」と言われる
- **シエラは死ぬ**。死に際に「来世の私もよろしくね」と言い残す → ここから悲劇(輪廻を追う物語)が始まる
- シエラは**同じ顔・記憶なし・違う経歴で転生を繰り返す**(輪廻転生ロリババア)。記憶障害持ち・眼鏡をかける生もある

## 4. シエラの転生体たち(2代目以降のハニー)

- 初代ハニー(シエラ)の死後、フェフェルだけが記憶を保持し、転生したシエラ(同じ顔・記憶なし)を毎回探し出す
- 「また来世でねっ」(シエラ) ⇔ 「俺はまだ記憶ある」(フェフェル)
- シエラ本人は毎回フレッシュ(初対面)なので「なんでそんなこと知ってるの?怖い」となるが、フェフェルは「そこまで忘れてしまったのか、これから一緒に思い出作ろうねっ」
- 繰り返すうちに、フェフェルは**「顔の系統が同じ」だけで反応するようになる**(ストライクゾーンの拡大)=ハニー選別の根源

## 5. ハニー選別に巻き込まれる女性たち

- フェフェルが「ハニー」と誤認した女性が複数いると発生する密室の生存競争(原文03)
- シエラの顔の系統の女性が巻き込まれるのか、無関係の女性もなのかは要確認

## 6. 城のおばあちゃんたち(シエラとは別)

- 後年、フェフェルが透明な鎖で城に繋いだおばあちゃんたち(原文03)
- 「主人公のおばあちゃん」は**シエラではない別人**(B19・正体未確定)。昔フェフェルの鎖の処刑形態を見たことがある
- この集団とハニー選別・シエラ系譜の関係は要整理
