# 勇者3人組: 紅蓮・奏多・素羅

元・邪神討伐パーティー。高校生で「諸悪の根源 邪神」(1000年間人類を苦しめた災害)を人類史上初めて討伐。
3章構成: 1章=邪神殺しの旅(高校生編) / 2章=解散後(大学生編) / 3章=宇宙人到来・人類代表パーティー(新入社員編)。

3人の共通項: 剣技だけは神に愛された美しさ。人格はどこか欠けている(金・時間・名誉への興味の欠落)。
3人だけのときは普通の大学生のように笑う。

## 紅蓮(ぐれん)「は? 気に食わねぇな」

| 項目 | 内容 |
|------|------|
| タイプ | 努力型。筋トレと実戦の執念で「人間の限界を超えた暴力」へ。超攻撃型(高速接近・重連撃・正面突破)。戦闘中テンションが上がると笑う |
| 現在 | 勇者権限を盾にした半・悪徳領主。「秩序維持には恐怖が必要」と本気で信じる。処刑が感情的 |
| 性格 | 短気・声が大きい・田舎ヤンキー気質。身内には甘い。努力信仰が強すぎて「生活が苦しい」を理解できない |
| 趣味 | 筋トレ・ラーメン屋巡り・ビートボックス・爆音系音楽。煙草は吸わない(「肺弱くなるから」) |

## 奏多(かなた)「大丈夫大丈夫、俺に任せて」

| 項目 | 内容 |
|------|------|
| タイプ | 才能型の天才。技巧戦(フェイント・誘導・心理戦)。相手を壊すように戦う |
| 現在 | 笑顔の悪徳業者気質。人脈・契約・情報で裏社会に浸透。挑発が異常に上手い。必ず裏がある |
| 性格 | 社交的・表裏が激しい・人の反応を見るのが好き。仲間への執着は強い。なんだかんだ面倒見が良い |
| 趣味 | 可愛いもの集め・猫・雑貨・男(「男って面白いじゃん」)。喫煙者。返り血の中で鼻歌 |

## 素羅(そら)「……別に」

| 項目 | 内容 |
|------|------|
| タイプ | 静の殺人機械。最小動作・急所・一撃・無音。気づいたら終わっている |
| 現在 | 独自の合理基準(「再発するなら止めるべき」)で危険人物を静かに処理。理由を説明しないため「理由なく人を殺す化け物」として恐れられる |
| 性格 | 無口・低体温・無感情に見えるが、実は3人で最も周囲を見ている。一番付き合いが良い |
| 趣味 | 重低音音楽・猫動画・深夜徘徊・男観察。喫煙者(深く長く吸う) |

## 確定事項(著者回答 2026-06-12)

- **「諸悪の根源 邪神」=男性エルフを全滅させた「諸悪の根源存在」(A3で確定)。** エルフ滅亡史と勇者編は直結する: 邪神の1000年災害の中で男性エルフ全滅(フェフェル胎児期)→後年、勇者3人(高校生)が討伐
- **3人はアイドルでもあり、バンド活動もしている(B11)。アクア(オタク令嬢)の推しはこの勇者パーティー。** 趣味の音楽設定(紅蓮=ビートボックス/奏多=鼻歌ボーカル/素羅=低音の合いの手)はバンドに直結。一推し・二推しが誰かは要確認(B17)

## 要確認メモ

- 3章「宇宙人到来」と、アゼンの対宇宙脅威(原文14)・魔王軍の目的(原文17)・フェフェルの宇宙行き(原文03)は同じ宇宙人/同じ時期か
- 勇者資格制度(民衆支持・人格評価)の設定は1章の前段として残すか
