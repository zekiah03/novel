# 第二十八話　けっこう長い

　　　　◆わたし◆

　一日が過ぎた。

　窓の高いところが暗くなって、また明るくなって、その明るさが真上まで来た。

　あの人が出ていったのが、前の日の夕方だ。

　二十四時間は、とっくに過ぎている。

　　　　◇

　誰も、消えなかった。

　最初に気づいたのは、青だった。

　緑の腕に口をつけたまま、顔を上げて、わたしを見た。

「……赤さん」

「なに」

「一日、経ってません?」

　わたしは、答えられなかった。

　答えられないということが、答えになった。

　白が、緑の背中から顔を出した。

「え、じゃあ」

「もう終わってるってこと?」

「じゃあ、なんで」

　わたしは、天井を見ていた。

　考えていたのは、あの人の顔だ。

　――一日で決まるようにしたの。

　――二十四時間。

　あの人は、そう言った。嬉しそうに言った。褒めてほしそうな顔で言った。

　それで、わたしは分かってしまった。

　あの人は、時間を数えられない。

　二十年一緒にいて、一度も正確だったことがない。「すぐ帰る」で三日空ける。「二日くらい」で六日いない。何百年生きた生き物にとって、一日と一週間は同じ長さなのだ。

　その人が、鎖に時計を入れた。

　入れたつもりで、入れたと思っている。

　でも、どこで鳴るのかは、本人も知らない。

「赤さん」

　青が言った。声が少し高くなっていた。

「いつ鳴るんですか」

「わかんない」

「わかんないって」

「わかんないの」

　わたしは、そこで初めて、この状況の本当の形を理解した。

　二十四時間なら、まだよかった。

　二十四時間なら、二十三時間五十分まで待って、最後に決めればいい。あるいは、あと三時間だから急ごう、と言える。

　**期限が分からないほうが、ずっと悪い。**

　いつ来るか分からないものは、常に「いま来るかもしれない」になる。

　次の一秒かもしれない。三日後かもしれない。

　だから、休めない。

　　　　◇

　わたしたちは、続けた。

　やることは単純だった。

　白と青が、緑の腕と肩に口をつけて、離れない。わたしが正面から緑を止める。緑が二人を振り落とそうとしたら、わたしが前から入って邪魔をする。

　それだけを、繰り返した。

　緑の動きは、確かに落ちていった。

　最初は、わたしを壁まで飛ばせた。半日で、押し返す程度になった。次の半日で、掴んで振り回すのが精一杯になった。

　落ちていった。

　でも、止まらなかった。

「言っとくけど」

　緑は、最初にそう言った。

「わたし、けっこう長いよ」

　意味は、途中で分かった。

　この人は、十四か十五から二十年、毎日体を作ってきた人だ。

　毎日だ。休まずに。

　その二十年が、全部、この人の中に溜まっている。

　わたしは花を見ていた。白は教科書を読んでいた。青は空気を読んでいた。

　この人は、殴っていた。

　三人がかりで生命力を吸って、丸一日かかって、まだ立っている。

　わたしたちが二十年で積んだものより、この人が二十年で積んだもののほうが、単純に多いのだ。

　　　　◇

　　　　◆僕◆

　王都の市は、いつ来ても面白い。

　外の町にはないものが、全部ある。

　まず花屋に行った。

　乾かした花を輪にしたやつが吊るしてあって、それが十六種類あった。全部いい。

「これ、ぜんぶください」

「ぜんぶ?」

「うん」

　店の人が変な顔をした。よく変な顔をされる。

　次に、布を見た。

　ハニーは布が好きだ。持って帰ると、広げて、しばらく見て、それから何かに使う。

　柔らかいのがいいと思う。前に硬いのを持って帰ったら、あまり広げなかった。

　柔らかいのを、六反。

　それから、化粧品の店に行った。

　ここがいちばん時間がかかる。

　わたしには違いが分からない。並んでいる筒は全部同じに見える。色の名前も読めない。

　だから、店の人に聞く。

「いちばん人気なのは?」

「こちらですね」

「じゃあそれ。あと二番目と三番目も」

「……全部お買い上げで?」

「うん」

　それから、菓子屋に寄った。

　焼いたやつと、干したやつと、白い粉のかかったやつ。

　パンも買った。柔らかいのと、硬いのと、中に何か入っているの。

　ハニーは硬いのが好きだ。前に「柔らかいのは口の中でなくなるから嫌」と言っていた。

　でも柔らかいのも買った。気が変わるかもしれない。

　両手がいっぱいになったので、袋を買い足した。

　袋を持つ手がなくなったので、もう一つ袋を買った。

　空を見たら、暗くなっていた。

　――あれ。

　二日で帰るって言った気がする。

　まあ、いいか。

　みんな仲良くしててね、って言ったし。

　　　　◇

　　　　◆わたし◆

　二日目の夜、緑が膝をついた。

　　　　◇

　それまでは、一度も膝をつかなかった。

　膝をついて、そのまま前に手をついて、それから、動かなくなった。

　白が、背中から下りた。

　青が、腕から口を離した。

　わたしは、動かなかった。

　二十年前を覚えている。心臓が止まったと思ってから、何度も戻ってきた。

　だから、動かなかった。

　緑が、顔を上げた。

　まだ生きていた。

　目が、白のほうを向いた。

「あんた」

「……はい」

「手、痛いだろ」

　白が、何も言えずに、自分の手を見た。

　二日間、緑の体に組んでいた手だ。指が固まって、開かなくなっていた。

「もう離せ」

　緑は言った。

「終わるから」

　わたしは、そこで動くべきだった。

　これは罠かもしれない。最後の力で誰かを道連れにするつもりかもしれない。

　わたしはそう考えた。ちゃんと考えた。

　考えて、それでも、動けなかった。

　白が、泣き出した。

　声を出して泣いた。二日間ずっと泣いていたのに、いちばん大きい声だった。

「麗華さん」

　わたしは、その音を聞いてしまった。

　名前だった。

　わたしが禁じた名前を、白は最後まで、ずっと頭の中で使っていたのだ。

　緑が、少し笑った。

　笑ったところで、力が抜けた。

　それきりだった。

　　　　◇

　わたしは、緑のところへ行った。

　首に手を当てた。動いていなかった。

　念のため、口の前に手をかざした。何も来なかった。

　それでもしばらく見ていた。

　顔を上げたら、白と青が、わたしを見ていた。

　二人とも、後ろに下がっていた。

　わたしは、そのとき自分がどんな顔をしているのか、分からなかった。

　でも、分かることはあった。

　この部屋で、最後まで止めなかったのは、わたしだ。

　二人が離れたあとも、わたしは離れなかった。

　二人がやめたあとも、わたしはやめなかった。

　白と青が見ているのは、緑の死体ではなかった。

　わたしだった。

　青が、白の袖を引いた。

　小さい声で、こう言った。

「一緒にやらないと、死ぬよ」
