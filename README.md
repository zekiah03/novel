### 次に書くところ

**六代目以降 → 誤認の始まり(顔の系統だけで反応する) → ハニー選別の発生**

013で鎖が戻り、彼は「繋げばどこにも行かない」ことを覚えてしまった。
次に必要なのは**誤認そのもの**。似ているだけの別人を「シエラ」と判定し始める段階。

そのために、まだ書いていない条件が二つある:

1. **目が悪くなる**(何百年も後、と009に書いてある)
2. **候補が複数になる**(これが起きるとハニー選別が発生する)

**仕込み済みの装置**(009〜013)。**全部シエラが善意で作った**:

| 装置 | 内容 | どう効くか |
|------|------|----------|
| 記憶の幅 | 外見を変え続け「顔なんて入れ物」と教えた | 顔の系統が同じだけで反応するようになる |
| 眼鏡 | 「ブサイク」と言われ二度とかけない | 数百年後に目が悪くなっても矯正せず、顔が滲む |
| **鎖は良いもの** | **迷子対策として生まれ、六十年「安心する」と言われ続けた** | **繋ぐとき、彼は善行のつもりでいる** |
| **忘れても終わりでない** | **認知症の六年。「また覚えればいいでしょ」** | 転生体が覚えていなくても動揺しない |
| 来世も自分 | 死の間際の嘘 | 誤認の許可を本人が与えた |
| 「もっと早く」 | 二代目に間に合わなかった後悔 | 相手がどんどん若くなる |
| 唯一の抑制 | 「シエラが怒るから人を減らさない」 | この歯止めが外れたとき何が起きるか |

※話数構成は原文の順番に縛られない。**面白さで組み直してよい。**
