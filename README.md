# 小説プロジェクト(異世界ファンタジー・群像劇)

「小説家になろう」投稿用の長編小説を管理するリポジトリ。
主人公約20人の群像劇。各地のキャラクターが徐々に集結し、戦いに至る物語。

## フォルダ構成

```
novel/
├── 原文/            ← 既に書いてある文章をそのまま入れる場所(加工しない)
├── 本文/            ← 整理・ブラッシュアップ済みの完成稿(1話 = 1ファイル)
├── 設定/
│   ├── キャラクター/  ← 1人 = 1ファイル
│   ├── 世界観.md
│   ├── 時系列.md      ← 作中年表(矛盾チェックの基準)
│   ├── 勢力と集結.md  ← 誰がいつどこで合流したか
│   └── 用語集.md
├── プロット/         ← 全体構成・章ごとのプロット
└── CLAUDE.md         ← 作業ルール
```

## 作業の流れ

1. 書いたもの・メモを `原文/` に入れる
2. Claude が読み込んで `設定/` の各ファイル(キャラ表・時系列・用語集)に整理する
3. 整理表と照合して矛盾点を洗い出す
4. ブラッシュアップした完成稿を `本文/` に置き、なろうへ投稿する
